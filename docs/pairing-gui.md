# Pi Go.app（macOS）

在仓库运行 `npm run build:macos`，把 `build/Pi Go.app` 放到「应用程序」后打开。需要 macOS 14、Node.js 和 Pi CLI。构建需要 Swift 工具链。首次安装扩展时，从仓库执行 `pi install "$PWD"`。

## 接管连接

1. 打开 Pi Go，选择「USB」，点击「接管连接服务」。应用会注册用户级后台宿主和 USB 桥。如果旧宿主仍在运行任务，等任务结束后再试。
2. USB 调试需要 DevEco Studio 的 HDC。已配对时选「重新连接」可恢复转发并打开手机；首次配对可通过 USB 递票，也可以在手机输入八位码。启用「插线自动连接」后，后台会为已配对且允许 USB 调试的手机恢复转发。退出 Pi Go 后该设置继续生效。
3. 验证 USB 后，分别选择「局域网扫码」和「公网」，确认显示的是现有入口地址，点击「接管连接服务」。原端口、Pi 数据目录、TLS 身份和配对凭证会沿用。新设备可通过二维码配对；电脑地址变更时需要在手机重新配对。
4. 公网继续使用既有 VPS 和 SSH 配置。若本机已按公网文档安装项目的隧道 LaunchAgent，Pi Go 会沿用原 SSH 参数并接管该服务。界面显示本机隧道进程状态，可用手机实测 VPS 到本机的连通性。

Pi Go 退出后，启用的后台服务由 macOS 继续运行，用户重新登录时会启动。「停用连接」关闭所选入口并保留配对；「撤销手机配对」使所选入口的凭证失效。手机可通过后台宿主打开历史会话，也可直接接入 Mac 上已加载 Pi Go 扩展的活跃 Pi CLI 会话。

后台服务从已安装的 App 内读取代码，请将 `Pi Go.app` 保持在安装位置。切换时保留 `~/.pi-go` 及 Pi 会话目录。日志位于 `~/Library/Logs`，文件名以 `dev.pi.go` 或 `com.alex.pigo.remote` 开头。
