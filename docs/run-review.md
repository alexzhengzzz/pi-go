# 任务收件箱和结果

手机「动态」汇集已配对电脑的会话结果、定时任务汇报和工作区提醒。会话完成、失败或停止后，每个会话保留最新一轮。点击卡片可查看运行详情和本轮回复，点「打开会话」可继续对话。升级前未保存正文的记录仍可从详情打开会话。待回答或确认的请求可从卡片进入会话处理，处理后从列表消失。普通会话的待处理卡使用 Pi daemon 暴露的扩展交互，终端内的原生交互仍由电脑处理。

定时任务汇报看完后，可在详情里点「从动态移除」，也可在列表左滑点「移除」。批量清理时，切到「定时」，从右上角菜单进入「批量管理」，勾选或全选后移除。原电脑上的任务计划和运行记录继续保留，可在「自动化 → 运行历史」查看。

会话结束后可在对应消息下打开「本轮结果」。结果包含运行前后观察到的工作区文件变化、识别出的验证命令及其状态、工具图片和可打开的产物。点选 Diff 中新版本的行会把文件、行号和片段加入会话草稿。提交由用户在输入框完成。

Diff 使用运行前后的工作区快照。此前已有且本轮期间保持不变的编辑不会出现在 Diff 中。同一工作区同时被其他程序写入时，快照无法判断每处变更的作者。结果和 Diff 在电脑上保留最近 120 次，超出快照范围时界面提示。Diff 仅显示已采集的小型文本文件，产物预览读取工作区当前文件。

## 开通后台系统通知

「我的 → 通知 → 运行结束通知」控制应用内横幅和本机通知。手机 Pi Go 在后台仍能同步收件箱时，普通任务结束会在系统通知栏显示状态和会话标题。任务完成时状态显示为「OK」。华为运动健康可以将同一条通知同步到手表。首次从手机启动任务时，可按系统提示允许 Pi Go 发送通知。退到后台时若有已知的运行，Pi Go 会申请系统短时任务来接收结果。系统挂起或结束 Pi Go 后，实时提醒依靠 Push Kit。

收件箱和结果卡可直接使用。后台系统通知使用 HarmonyOS Push Kit，由 Mac 的 Pi Go 桥在手机退后台后投递。

1. 在 AppGallery Connect 为 `com.alex.pigo` 开通 Push Kit。将 DevEco Studio 的签名关联到该应用，重新生成启用 Push Kit 的签名配置。正式服务提醒需要符合 Huawei `WORK` 消息分类要求。[开通 Push Kit](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-guides/push-config-setting/) · [通知分类](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/push-apply-right/)
2. 从同一项目下载有 Push Kit 权限的服务账号 JSON。将该文件以 `0600` 权限放到电脑的 Pi Go 状态目录，默认路径为 `~/.pi-go/push-service-account.json`。无界面启动时也可通过 `PIGO_PUSH_ACCOUNT_FILE` 指定路径。联调可在账号 JSON 中添加布尔字段 `testMessage` 并设置为 `true`。服务账号只由 Mac 读取。[服务账号鉴权](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/push-jwt-token/)
3. 更新手机和 Mac 两端，并重新加载已在运行的 Pi CLI 扩展。重启 Mac 桥以载入服务账号，在手机「我的 → 通知 → 后台通知」开启开关，然后允许系统通知。已配对且桥可达时手机会登记 Push Token。
4. 通过蜂窝网验证锁屏、冻结及系统清理进程后的通知到达，分别点开完成和待处理通知。再在 Mac 答复一个已发送通知的请求，确认手机点开后显示该请求已结束。验证前保持 Mac 在线，并确保点击时手机能通过至少一种已配对入口访问 Mac。

Push Kit 远程通知只包含通用状态、设备定位标识和不透明记录 ID。会话正文、项目路径、命令、Diff 和文件通过现有已配对连接读取。关闭后台通知后，手机会在连接到对应桥时撤销登记。电脑撤销配对后，该连接的推送登记立即失效。

## 手表提醒

手表提醒默认开启，升级时沿用此前保存的设置。Pi Go 可向华为运动健康当前连接且支持模板化通知的手表发送普通任务完成、失败、停止、待处理和定时任务结果。同一事件只投递一次，投递记录在本机保留最近 240 条。无需开发或安装独立手表 HAP，也不需要用 USB 连接手表。

1. 在 AppGallery Connect 为 `com.alex.pigo` 申请 Wear Engine 服务及消息通知权限，并使用关联该应用的签名重新构建手机 HAP。[申请 Wear Engine 服务](https://developer.huawei.com/consumer/cn/doc/harmonyOS-guides/wearengine_apply)
2. 在华为运动健康中配对手表并保持连接，手表关闭勿扰并开启振动。手机需登录华为账号并同意 Wear Engine 服务协议。
3. 保持 Pi Go 运行，完成一次任务，检查手表是否收到提醒。

Wear Engine 主动提醒由手机上的 Pi Go 投递。应用被系统冻结或清理后，后台到达仍依靠上述 Push Kit；需要在此时同步到手表，还需在华为运动健康的「消息通知」中允许 Pi Go。手表是否弹出和振动由佩戴状态、勿扰及系统通知设置决定。
