# 同一 Wi‑Fi：HTTPS 配对

LAN 与 USB 是两个独立入口。USB 继续只监听回环地址；LAN 手动启用，只在指定的本机私有 IPv4 地址上监听 TLS，并拒绝非私有 IPv4 来源、错误 Host 和带 Origin 的请求。不用于公网或端口映射。

异地使用请配置独立的[公网配对入口](remote.md)。局域网与公网服务可以同时运行。

1. 按 [Pi Go.app 安装说明](pairing-gui.md) 安装 App 和 Pi 扩展。打开 Pi Go.app，选择「局域网扫码」和本机私有 IPv4 地址，启动局域网服务并生成二维码。
2. 手机与电脑使用同一 Wi-Fi。在 Pi Go 切到「局域网」，点「扫码导入」并完成配对。「发现电脑」显示的是来自 UDP 18976 的未验证地址。配对包包含地址、证书、公钥指纹与两分钟单次票据。手机验证 TLS 证书和公钥指纹后才发送票据，通过 HUKS 加密保存连接凭证。
3. 在 Pi Go.app 中可以停用连接或撤销手机配对。每个入口只保留一个活跃配对，新配对成功后替换旧凭证。

手机 App 重启后可沿用已保存的连接。桥用同一 IP、端口和 Pi 数据目录重启时会恢复配对与仍在有效期内的 TLS 证书。电脑 IP 变更后须停旧桥，按新 IP 启动并重新配对。证书到期后，重启桥并重新配对可更新手机保存的证书。

## 真机验收

鸿蒙真机在没有 LAN 端口 USB 转发的情况下，拒绝了错误公钥指纹，接受正确配对包。强制停止再启动 App 后自动恢复配对，能发送消息并收到离线模型回复。桌面撤销后，手机回到配对页并显示撤销提示。

真机也通过 UDP 广播发现了电脑，显示为未验证地址，并能打开系统二维码扫描界面。Mac 端的二维码解码已验证与原始配对包逐字一致；用真机相机扫描桌面二维码并完成配对的整条路径尚未验收。

## 多电脑

在聊天页点「电脑」返回配对列表，这不会删除凭证。可再配对一个 LAN 或 USB 地址，或从列表切换。同一地址重新配对时替换该条记录；USB 上的不同电脑应使用不同的反向转发端口。手机最多保留 12 条记录，重启时恢复上次连接的地址；如果上次停在列表，就不主动连接。旧版单条配对可直接读取。

列表「移除」只删除所选电脑在手机上的凭证。要吊销凭证，请在该电脑的 Pi Go.app 中选择「撤销手机配对」。某台电脑返回撤销后，手机移除该条记录，不影响其他电脑。草稿按电脑和会话分别留在当前 App 进程内，不持久化。
